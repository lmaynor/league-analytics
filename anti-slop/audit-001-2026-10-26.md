## Resolution Details

### 1. [HIGH] R-02 Copywriting: Forbidden em dash character in Weekly Recap
- **Resolution:** Replaced the em dash in `site/js/tab-scoreboard.js` with natural conversational parentheses:
  ```javascript
  narrative: `Escaped with a ${lucky.score} victory despite a ${xwVal.toFixed(1)}/9 xWin performance (would have lost to ${9 - Math.floor(xwVal)} other teams).`
  ```
- **Verification:** `grep -n "—" site/js/tab-scoreboard.js` returned 0 matches. **PASS**.

---

### 2. [HIGH] R-25 & R-34 Color Contrast: Dark theme badge contrast failures
- **Resolution:** Added dedicated high-contrast dark theme color tokens in `site/style.css` for status badges:
  ```css
  :root[data-theme="dark"] .award-badge.bad { background: color-mix(in oklch, #ef4444 20%, transparent); color: #f87171; }
  :root[data-theme="dark"] .award-badge.lucky { background: color-mix(in oklch, #10b981 20%, transparent); color: #34d399; }
  :root[data-theme="dark"] .award-badge.drama { background: color-mix(in oklch, #f59e0b 20%, transparent); color: #fbbf24; }
  ```
- **Verification:** Ran `contrast-check.py` against `--color-paper` in dark mode (`#1c1e28`):
  - `.award-badge.lucky` (`#34d399`): **8.63:1** (WCAG AA PASS).
  - `.award-badge.drama` (`#fbbf24`): **9.94:1** (WCAG AA PASS).
  - `.award-badge.bad` (`#f87171`): **6.00:1** (WCAG AA PASS).
